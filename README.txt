==========================================================
  CounselBook  -  School Counsellor's Record Book
==========================================================

Nothing to install. Works offline on any Windows 10/11 PC
(it uses Microsoft Edge, which comes with Windows).

----------------------------------------------------------
STARTING
----------------------------------------------------------
1. Copy this whole "counselbook" folder to the computer
   (e.g. D:\CounselBook). Keep all files together.
2. Double-click  "Start CounselBook.bat".
3. (Optional) Double-click "Create Desktop Shortcut.bat" once
   to get a CounselBook icon on the desktop.

FIRST RUN: enter the school name, then create the
ADMINISTRATOR login and the COUNSELLOR login. Write down the
RECOVERY KEY that is shown; it is the only way back in if the
admin password is forgotten.

----------------------------------------------------------
LOGINS & PERMISSIONS (Admin -> "Users & access")
----------------------------------------------------------
The admin can create more logins and decide, section by
section, what each person sees: No access / View / Edit.
Ready-made roles:
  - Counsellor            : full access
  - Principal / Senior    : reports + activities only,
                            student names hidden
  - Assistant / Teacher   : limited view, can manage follow-ups
  - Custom                : choose everything yourself
Extra switches per login: "Hide student identities" and
"Can read confidential notes".

----------------------------------------------------------
WHAT'S INSIDE
----------------------------------------------------------
Today        Who to meet today, overdue follow-ups, high
             priority cases, this month's numbers.
Students     Student list (name, class, contacts, parent no.),
             filters, priority flag, open/closed case status,
             archive for passed-out students.
Case file    Timeline, sessions, follow-ups, attachments
             (photos of forms/letters, PDFs), profile,
             "Export PDF" of the full student history.
Sessions     Date, time, duration, type, issue tags, SOAP / DAP
             / GIRP / free-text templates, quick phrases,
             next steps, confidential flag, auto follow-up.
             Group sessions: add several students.
Follow-ups   Reminders (Overdue / Today / Upcoming / Done),
             export to Outlook/Google Calendar (.ics file).
Search       Box at the top (Ctrl+K) searches everything.
Reports      Monthly sessions & hours, issue-wise, class-wise,
             session types, referrals, gender, priority.
             * "Present to seniors": full-screen slide show
             * "Year-end report (PDF)": anonymised report
             * "Export CSV" for Excel
             Reports never show student names.
Activities   50 counselling activities with steps, debrief
             questions and printable worksheets, plus 9
             interactive tools for the smart board: Breathing
             Bubble, 5-4-3-2-1 Grounding, Feelings Wheel, Mood
             Meter, Question Spinner, Scenario Cards, Worry
             Sorter, Strengths Picker, Activity Timer.
             "Log as session" records the activity you used.
Games & art  10 games children love (smart board / touch friendly):
             Feelings Memory Match, Calm Catcher, Worry Balloon
             Pop, Balloon Breath, Emotion Detective, Thought
             Sorter, Feelings Journey Board Game (2-4 players),
             Gratitude Garden, Superhero Me (printable hero card),
             Kindness Quest (choose-your-path stories).
             Art therapy: Mandala Maker (mirror drawing) and Art
             Studio (brush, paint bucket, eraser, templates: mask,
             heart map, feelings jar, body map, inner weather,
             bridge, comic strip, worry monster, safe place),
             plus 10 printable art-therapy worksheets.
             Only high scores are stored; no child data is saved.
Settings     School name, academic year, auto-lock time, issue
             tags, classes, templates, YEAR ROLLOVER (promotes
             every class; the top class is archived as
             "passed out").

PDFs: on any Print button, choose "Save as PDF" as the printer.

----------------------------------------------------------
SECURITY
----------------------------------------------------------
- All data is encrypted (AES-256) and stays on this computer.
- Password / PIN for every login; locks itself when idle
  (default 5 min; change in Settings). Ctrl+L locks at once.
- No internet is used. Nothing is uploaded anywhere.
- Data lives in a private Edge profile at
  %LOCALAPPDATA%\CounselBook, separate from normal browsing,
  so clearing Edge history will not delete it.

BACKUPS (important!)
  Backup & restore -> "Create encrypted backup" -> choose your
  USB drive or Google Drive folder. Do it weekly. The app
  reminds you. Restoring on a new PC needs a login from the backup.

----------------------------------------------------------
GOOD TO KNOW
----------------------------------------------------------
- Voice typing: click in any note box and press
  Windows key + H (Windows dictation). The mic buttons also
  work when Edge's speech service is available.
- Fingerprint / face unlock is not possible in an offline
  app like this; use a password or a 6-digit PIN.
- Always open the app with "Start CounselBook.bat", so the
  same private profile (and your data) is used.
- Dark mode: moon icon at the bottom left.
